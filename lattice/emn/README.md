# `lattice/emn` — verification and pricing of the EMN Catalan note

Document: `consolidation/EMN_VERIFICATION.md`.
Source under test: `chatgpt-research-archive/A Non-Eisenstein Catalan Programme from the
Eskandari-Murty-Nemoto Motive.md`.  Paper: arXiv:2510.20648 (Eskandari, V. Kumar Murty, Nemoto).

## Libraries

| file | what it does |
|---|---|
| `emnexact.py` | exact `I_{m,t} = \iint_Delta x^m y^m (1-x^2-y^2)^{-(t+1)}` as `(a, b)` with `I = a + b G` |
| `emngen.py` | the same for `T(p,q,t)` with `p != q` (symmetrised pairs), needed for the saddle-killer family |

Both work in the module `Q + Q*pi + Q*log2 + Q*pi*log2 + Q*G` and assert that the
`pi` / `log2` components cancel — an independent check of EMN Theorem 1.1.1 on every value.
Atoms: Wallis `Cw`, `Pw(r) = int (1+sin)^r`, `Ew`, `Lw = int sin^k log sin`,
`Sw = int sin^k log(1+sin)` with `k Sw(k) = (k-1)Sw(k-2) + Cw(k-1) - Cw(k)`, `Sw(0) = 2G - (pi/2)log2`.
