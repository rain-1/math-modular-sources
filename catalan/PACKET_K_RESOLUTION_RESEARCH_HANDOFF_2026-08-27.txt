XI. DECISIVE FIXED-SOURCE DETERMINANT CONSERVATION / NO-GO THEOREM
========================================================================

This is currently the most important result for Packet K.

Take Packet E's genuine fixed coefficient evaluation map in the scaled z-coordinate:

    psi_D : E_D tensor Q_2 -> Q_2^{2D}.

Relative to the standard Hermite source lattice,

    v_2(det psi_D) = D.

Lambda_D^0 by a saturated/enlarged lattice Lambda_D^EZ with arithmetic-degree gain

    Omega_D.

Write

    Lambda_D^EZ = S_D Lambda_D^0.

    v_2(det S_D) = -Omega_D.

The SAME evaluation map in the new source basis has matrix

    psi_D S_D.

Therefore exactly

    v_2(det(psi_D S_D))
      = D - Omega_D.

Since

    Omega_D
      = 4D^2 + 4D - 4S_D,

one obtains

    -v_2(det(psi_D S_D))
      = Omega_D - D
      = 4D^2 + 3D - 4S_D
      = 4D^2 + O(D log D).

THIS IS A DETERMINANT-LINE IDENTITY, NOT A HEURISTIC.

Conclusion:

    if the E/Z lattice enlarges the source degree by about 4D^2,
    the fixed Hermite evaluation map necessarily acquires about 4D^2
    of adverse determinant height.

The hoped-for theorem

    "gain 4D^2 in source degree, while later p=2 evaluation costs only o(D^2)"

is impossible for this fixed target/evaluation map.

If one also changes the target lattice by T_D, then

    v_2 det(T_D^{-1} psi_D S_D)
      = D - Omega_D - v_2(det T_D).

To restore integrality or small evaluation determinant, one must move essentially the
same 4D^2 amount into the target degree.

The volume has moved, not disappeared.

This is exactly what a correct adelic slope theorem is supposed to record.

1. Packet C binary-minor method
-------------------------------

For lower-triangular matrices whose entry valuation is controlled by a difference
d = r-m, Packet C proves:

    sum d_i <= q(D-q)

for terms in q-active-index minors.

This converts entrywise valuation formulas into sharp lower bounds on all minors,

This machinery should be reusable for the composed E/Z-Hermite map.


2. Packet E binary Hankel structure
-----------------------------------

After division by P and reduction mod 2, the Hermite tail matrix is controlled by the

    a_n = 1_{n is a power of 2}.

Its Hankel determinants are all odd after the global factor 2^D is removed.

This exceptionally rigid mod-2 structure should make it possible to analyze minors of
the E/Z-adapted Hermite matrix, not only its determinant.


3. Packet B selected CD unimodularity
-------------------------------------

The selected-mode CD transport is exactly Z_2-unimodular.

Thus a future full-polygon calculation can insert/remove this selected CD block without
changing the Smith polygon, PROVIDED the common complement is genuinely the same
integral quotient.

This is still useful; B should not be discarded.


4. Newton divided powers
------------------------

The consecutive binomial matrix

    (binom(N+i,j))

is unimodular.

Thus same-index local projective divisors can be stacked into high-dimensional
filtered matrices without paying a determinant from the interpolation itself.

Again, the source-lattice/evaluation-height cost must still be included.


5. Archimedean fold optimization
--------------------------------

Packet J already solves a nontrivial rearrangement problem for D fold directions among
2D pivot orders.

A future K should probably preserve this discrete flag structure all the way from the
finite place instead of summing the finite place first.
